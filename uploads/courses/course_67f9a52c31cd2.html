Balise html 

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Titre de la page</title>
    <link rel="stylesheet" href="styles.css">
    <script src="script.js" defer></script>
</head>
<body>
    <!-- Contenu de la page -->
</body>
</html>
  • <!DOCTYPE html> : Indique la version HTML utilisée (HTML5 dans cet exemple).
  • <html> : Élément racine de la page.
  • <head> : Contient des métadonnées, liens vers des fichiers CSS, scripts, etc.
  • <meta charset="UTF-8"> : Spécifie l'encodage des caractères de la page.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> : Optimise l'affichage sur les appareils mobiles.
  • <title> : Définit le titre de la page.
  • &emsp; : tabulation (Em Space)
  • &nbsp; : espace (Non-Breaking Space)

2. Balises de texte :

  • <h1> à <h6> : Titres de différentes tailles.
  • <p> : Paragraphe.
  • <strong> : Texte en gras.
  • <em> : Texte en italique.
  • <u> : Texte souligné.
  • <br> : Saut de ligne.
  • <hr> : Ligne horizontale.

3. Liens et images :

  • <a href="url">texte du lien</a> : Crée un lien hypertexte.
  • <img src="url" alt="description"> : Insère une image.

4. Listes :

  • <ul> : Liste non ordonnée.
  • <ol> : Liste ordonnée.
  • <li> : Élément de liste.

5. Tableaux :

  • <table> : Définit un tableau.
  • <tr> : Ligne d'un tableau.
  • <td> : Cellule de données d'un tableau.
  • <th> : En-tête de tableau.
  • <form> : Définit un formulaire.
  • <thead>
  • <tbody>

6. Formulaires :

  • <input> : Champ de saisie.
  • <textarea> : Zone de texte multiligne.
  • <select> : Liste déroulante.
  • <button> : Bouton du formulaire.

7. Divisions et regroupements :

  • <div> : Groupe de contenu générique.
  • <span> : Groupe de texte en ligne.

8. Balises sémantiques :

  • <header> : En-tête de la page ou de section.
  • <footer> : Pied de page de la page ou de section.
  • <nav> : Liens de navigation.
  • <main> : Contenu principal de la page.
  • <article> : Contenu autonome, comme un article de blog.
  • <section> : Section générique d'une page.
  • <aside> : Contenu à part, comme une barre latérale.

9. Balises pour le multimédia :

  • <audio> : Intégration de fichiers audio.
  • <video> : Intégration de fichiers vidéo.
  • <source> : Fournit des sources alternatives pour les éléments <audio> et <video>.
  • <iframe> : Intègre une page web dans une autre.
  • <embed> : Intègre des contenus multimédias externes.

10. Balises pour les éléments de texte spécifiques :

  • <abbr> : Abréviation ou acronyme.
  • <cite> : Titre d'une œuvre citée.
  • <code> : Texte formaté en code.
  • <mark> : Texte marqué.
  • <sub> : Texte en exposant.
  • <sup> : Texte en indice.

11. Balises pour la structure de navigation :

  • <menu> : Menu de commandes.
  • <details> : Conteneur pour des informations supplémentaires pouvant être masquées ou affichées.
  • <summary> : Titre ou légende pour un élément <details>.
  • <nav> : Section de navigation.

12. Balises pour les éléments interactifs :

  • <button> : Bouton interactif.
  • <input type="checkbox"> : Case à cocher.
  • <input type="radio"> : Bouton radio.
  • <input type="submit"> : Bouton de soumission de formulaire.
  • <input type="reset"> : Bouton de réinitialisation de formulaire.
